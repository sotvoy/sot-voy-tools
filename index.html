The internet has enough tools that make simple things feel complicated.

SOT VOY Tools is being built in the opposite direction: focused pages, clear controls, useful explanations and results you can understand immediately.

As the library grows, the standard stays the same. More tools should mean more usefulness—not more clutter.

Straight answers to useful questions.

Is SOT VOY Tools free? +

The core tools are being designed to be freely accessible. Advertising may support the platform as it grows.

Do I need an account? +

No account should be necessary for ordinary browser tools.

Will my information be uploaded? +

Tools that can safely process information locally are designed to do so. Each individual tool will state its data behavior clearly.

How many tools will there be? +

The platform is designed to grow into a large library while keeping search and navigation manageable.
